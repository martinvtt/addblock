# Privacy policy

Effective date: 2026-10-28. Applies to Addblock 0.5.0.

Addblock has no telemetry, user account, remote analytics, or server collecting
browsing data. It does not send page content, browsing history, or filter matches
to the project authors. Filtering and popup decisions take place in the browser.
Filter lists are bundled; there are no automatic runtime list downloads.

The distribution build keeps cosmetic counts in Chrome session storage. The
development build can additionally keep blocked domain names (not complete URLs)
and request counts, capped at 100 domains per tab, with 20 displayed. Records are
reset on page navigation, removed on tab close, and cleared by the browser at
session end. Pause and site exceptions persist as local Chrome dynamic rules;
users can change them in the popup or remove extension data by uninstalling.

HTTP/HTTPS host access is used for local DOM filtering and popup interception.
No page content is retained by the extension. Source/license links open external
websites only when clicked, subject to those websites' policies. Updating the
bundled AdAway source is an explicit developer command, not extension activity.

This file can be hosted as the privacy-policy page when publishing a Store
listing. No public listing or policy URL has been created by this release.
