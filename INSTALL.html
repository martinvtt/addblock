ADDBLOCK / 0.5.1

Less advertising.
A simple first installation.

No account, Python or Ubuntu required. Works with Chrome and Microsoft Edge.

1. Extract the whole ZIP

Right-click the downloaded archive and choose Extract all. Keep the extracted folder somewhere permanent, such as Documents / Addblock. Do not select the ZIP itself.

2. Open your browser’s extension page

Copy the appropriate address into the address bar:

Microsoft Edge: edge://extensions

Google Chrome: chrome://extensions

Switch on Developer mode (Mode développeur).

3. Load Addblock

Choose Load unpacked (Charger l’extension décompressée / non empaquetée). Select the extracted folder containing manifest.json.

Pin Addblock using your browser’s Extensions menu, then refresh your websites.

Using and updating

  • Open Addblock’s icon to pause protection or allow a particular site.
  • For updates, replace the files in the same folder, click Reload on the extension page, then refresh your websites.
  • To uninstall, choose Remove on the extension page. Browser-managed extension settings may be deleted.

This is a manually installed extension, not a Chrome Web Store or Edge Add-ons listing. Browser validation cannot be bypassed by this package. There are no automatic updates. Some ads may remain and some legitimate popups may be blocked.

Sources and privacy

Keep the extracted folder: moving or deleting it prevents the extension from loading.
